
# EDFA Performance Analysis - Virtual Lab

Interactive 3D educational demonstration of an Erbium-Doped Fiber Amplifier (EDFA), built with Three.js.

## Features
- 3D EDFA setup
- Adjustable pump power and input signal
- Gain, output power and model noise figure
- Desktop camera controls
- Optional WebXR VR mode

## Run
Open index.html in a modern WebGL browser with internet access.

WebXR requires a compatible browser, headset and HTTPS.

## Educational model note
Gain and noise figure are simplified illustrative indicators, not calibrated experimental measurements or commercial EDFA specifications.
